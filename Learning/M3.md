# M3 — Controller training

[Start here](../START_HERE.md) · [Next: M4](M4.md)

**Goal:** train a controller to reach **0.6 rad** and hold it there. Implement `train_policy(L, b, iters=300, lr=0.01, seed=1)` in `policy.py`.

## Assignment

1. Use the supplied **2 → 32 → 1** network. Inputs: `[th − TARGET, om]`, shape **(n, 2)**. Raw output: **(n, 1)**.
2. Convert output to torque with `UMAX × tanh(output)`, where `UMAX=10`. Remove only the final singleton axis to get **(n,)**.
3. Each update, sample **32** starting angles uniformly in **[−0.1, 0.1)** and set velocities to zero. Simulate **150 steps**, choosing fresh torque from each current state.
4. Average `(th − TARGET)² + 0.01 × om²` across trajectories and all resulting time steps. Preserve gradients through torque and physics.
5. Use Adam for one update per rollout. Train network parameters; keep L and b fixed. Honor the iteration, learning-rate, and seed arguments.
6. Return the raw-output policy network and retain numeric training costs. Keep outer torque scaling outside the network; evaluation applies it too.
7. Train nominal `(L=1.0, b=0.1)` and calibrated policies with matching settings and seeds. Save both training curves in one labeled plot.

Useful syntax: `torch.stack`, `.squeeze(-1)`, `torch.tanh`, `torch.rand`, `policy.parameters()`, `torch.optim.Adam`.

## Checks

- Shapes match; torque stays within **[−10, 10]**.
- States, costs, and gradients are finite; network parameters change.
- In each policy's own simulator, compare before/after training using angles **[−0.1, −0.05, 0, 0.05, 0.1]**, zero velocities, and 150 steps. Aim for lower mean objective and mean absolute angle error below **0.1 rad** over the last 50 steps.
- `python -m pytest -q` passes.

Explain how cost trains the network without correct-torque labels. Costs may fluctuate between updates. Training curves alone do not establish better transfer—compare on the shared reference system in [M4](M4.md).
