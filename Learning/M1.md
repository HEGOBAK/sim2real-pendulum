**Goal:** implement `step` and `rollout` in `sim.py`, preserving gradients to L and b.

## One physics step

`step(th, om, u, L, b)` takes angle, velocity, and torque shaped **(n,)**; scalar L and b apply to every pendulum. Keep the supplied `G`, `M`, and `DT` constants.

Calculate in this order:

```text
acceleration = −(G/L) × sin(th) − (b/(M × L²)) × om + u/(M × L²)
new velocity = om + DT × acceleration
new angle    = th + DT × new velocity
```

Return `(new angle, new velocity)`. Using the updated velocity is semi-implicit Euler.

Check: for `th=0.1, om=0, u=0, L=1, b=0`, expect angle ≈ **0.09960825**, velocity ≈ **−0.01958732**.

## Rollout

`rollout(th0, om0, U, L, b)` starts from states **(n,)** and a torque schedule **(n, T)**. Call `step` for each time step and return angles shaped **(n, T)**, recording the angle after each step.

Useful syntax: `torch.sin`, `U[:, t]`, list `.append()`, and `torch.stack(..., dim=1)`. Preserve the computation graph: avoid NumPy, `.detach()`, `.item()`, `torch.no_grad()`, and recreating calculated states with `torch.tensor`.

## Checks

Run `python -m pytest -q` for period and gradient checks. Also run this batch check from the project root (or save its Python body in a practice file):

```sh
python - <<'PY'
import torch
from sim import rollout
th0 = torch.tensor([0.1, 0.3])
om0 = torch.zeros(2)
U = torch.zeros(2, 50)
L = torch.tensor(1.0, requires_grad=True)
b = torch.tensor(0.1, requires_grad=True)
Y = rollout(th0, om0, U, L, b)
assert Y.shape == (2, 50) and torch.isfinite(Y).all()
for i in range(2):
    single = rollout(th0[i:i+1], om0[i:i+1], U[i:i+1], L, b)
    assert torch.allclose(Y[i], single[0])
Y.square().mean().backward()
assert L.grad is not None and torch.isfinite(L.grad).all()
assert b.grad is not None and torch.isfinite(b.grad).all()
print("Batch and gradient checks passed")
PY
```
