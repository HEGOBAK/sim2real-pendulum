## 1. One physics step — start here

Implement only `step(th, om, u, L, b)` first.

| Name | Meaning | Typical shape |
|---|---|---|
| `th` | Angle in radians | `(n,)` |
| `om` | Angular velocity in radians/second | `(n,)` |
| `u` | Applied torque | `(n,)` |
| `L` | Length | Scalar `()` |
| `b` | Damping coefficient | Scalar `()` |
| `G`, `DT`, `M` | Gravity, time step, mass | Already-defined constants |

`n` is the number of independent pendulums, like examples in a batch. Scalar length and damping apply to all of them through broadcasting.

Translate these equations into tensor operations, in order:

1. Acceleration = `−(G/L) × sin(th) − (b/(M × L²)) × om + u/(M × L²)`.
2. New velocity = old velocity + `DT × acceleration`.
3. New angle = old angle + `DT × new velocity`.

Return `(th_next, om_next)`. Using the NEW velocity in the angle update is semi-implicit Euler.

Syntax needed: `torch.sin(th)`, `L ** 2` for squaring, ordinary arithmetic, and `return th_next, om_next`. Use new variables instead of changing input tensors in place. Replace the `step` TODO and its `raise NotImplementedError`; leave `rollout` for the next checkpoint.

Exact numerical check: with angle `0.1`, velocity `0`, torque `0`, length `1`, damping `0`, expect new angle approximately `0.09960825` and new velocity approximately `-0.01958732`. Save and say “check” for the assistant to run this case.

## 2. Roll out a trajectory

Implement `rollout(th0, om0, U, L, b)` using your `step` function.

- Starting states `th0`, `om0`: `(n,)`.
- Torques `U`: `(n, T)` — rows are pendulums, columns are time steps.
- Returned angles: `(n, T)` — each column records the angle AFTER that step. Do not add the starting angle as an extra column.

Write these operations yourself:

1. Start local angle and velocity variables from the initial states and create an empty list of angles.
2. Loop over the `T` time steps.
3. Select the current torque for every pendulum and call `step`.
4. Keep both returned states for the next step; append the new angle to the list.
5. Stack the list into the required return shape.

Syntax needed: `U.shape[1]`, `range(...)`, `U[:, t]` (all rows, column t), tuple unpacking, `angles.append(th)`, and `torch.stack(angles, dim=1)`.

Preserve gradients: no NumPy, `.detach()`, `.item()`, or `torch.no_grad()` inside these functions. Do not wrap calculated states in `torch.tensor(...)`; stack them instead. Python loops and lists are fine.
