# M2 — System identification

[Start here](../START_HERE.md) · [Next: M3](M3.md)

**Goal:** fit length L and damping b from measured motion in `calibrate.py`. Choose your own code structure.

## Assignment

1. Keep `calibrate(iters=400, lr=0.05)` and honor its arguments.
2. Call `collect_real_data()` once. It returns starting states **(n,)**, torques U **(n, T)**, and measured angles Y **(n, T)**. Keep this data fixed during fitting.
3. Start at **L=1.0, b=0.1**. Optimize `log_L` and `log_b`; use their exponentials in `rollout` to keep physical values positive.
4. Use Adam to minimize mean squared error between rollout angles and Y.
5. Return `(L_cal, b_cal, loss_history)`: two Python numbers and numeric losses. The last loss must describe the returned final parameters.
6. Print initial/final loss and fitted values. Save a labeled plot to `figures/m2_calibration_loss.png`.

## Finish when

- `python calibrate.py` runs and the plot matches the recorded losses.
- L and b are finite and positive; final MSE is below initial MSE.
- Both log parameters receive finite gradients; `python -m pytest -q` passes.
- You can explain why logarithms are optimized and trace loss back to them.

Low fitting loss does not prove exact parameter recovery. Record your actual results, then continue to [M3](M3.md).
