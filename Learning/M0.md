# M0 — PyTorch basics

[Start here](../START_HERE.md) · [Next: M1](M1.md)

**Goal:** learn `y = 2x + 1` in `m0_practice.py`.

Read the [PyTorch basics](https://docs.pytorch.org/tutorials/beginner/basics/intro.html) sections on tensors, building a network, autograd, and optimization as needed.

## Assignment

1. Use inputs `[-2, -1, 0, 1, 2]` and targets `[-3, -1, 1, 3, 5]`, both floating-point tensors shaped **(5, 1)**.
2. Fit `nn.Linear(1, 1)` using `nn.MSELoss()` and SGD with learning rate **0.05** for **300 updates**. Learn the weight and bias; do not assign the answers.
3. Include prediction, loss, gradient clearing, backpropagation, and parameter updates.
4. Print initial/final loss, weight, bias, and predictions for **3 and 4** without tracking gradients.

Run: `python m0_practice.py`.

## Finish when

- Final loss is below **0.001**; weight ≈ **2**, bias ≈ **1**.
- Predictions are within **0.1** of **7 and 9**.
- You can explain shape `(5, 1)`, how `backward()` connects to `step()`, and why gradients must be cleared.

Useful syntax: `torch.tensor`, `model.parameters()`, `torch.optim.SGD`, `.zero_grad()`, `.backward()`, `.step()`, `torch.no_grad()`.

Record your results, then continue to [M1](M1.md).
