# M0 — PyTorch basics

[Start here](../START_HERE.md) · [Next: M1](M1.md)

## End product

Train a tiny model to learn **y = 2x + 1**, then explain how it learned. Work in `m0_practice.py` in your own project copy. The repository's existing file is a completed reference, so attempt the task before reading its solution.

## Read only what you need

Use the [official PyTorch Learn the Basics tutorial](https://docs.pytorch.org/tutorials/beginner/basics/intro.html): **Tensors**, **Build the Neural Network**, **Automatic Differentiation**, and **Optimizing Model Parameters**. Focus on shapes, `nn.Linear`, parameters, loss, `backward()`, and optimizer updates. Image datasets, transforms, and saving models are not needed for this assignment.

## Mini self-test assignment

Use these exact examples:

```text
x: -2, -1, 0, 1, 2
y: -3, -1, 1, 3, 5
```

1. Create floating-point input and target tensors, each shaped **(5, 1)**.
2. Use **nn.Linear(1, 1)**; learn its weight and bias instead of assigning the answer directly.
3. Use **nn.MSELoss()** and **SGD with learning rate 0.05**.
4. Train for **300 updates**, using all five examples each time. Include clearing gradients, prediction, loss calculation, backpropagation, and the optimizer update. Choose your own code organization.
5. Print the loss before and after training, the final weight and bias, and predictions for new inputs **3 and 4**, evaluated without gradient tracking.

Run from the project root with your environment activated:

```sh
python m0_practice.py
```

Useful syntax to look up: `torch.tensor`, `dtype=torch.float32`, `nn.Linear`, `model.parameters()`, `torch.optim.SGD`, `.zero_grad()`, `.backward()`, `.step()`, and `torch.no_grad()`.

## Completion checks

- Final training loss is **below 0.001**.
- Learned weight is close to **2** and bias is close to **1**.
- Predictions for 3 and 4 are within **0.1** of **7 and 9**.
- You can explain why input shape is `(5, 1)` rather than `(1, 5)`.
- You can trace how `loss.backward()` supplies the gradients used by `optimizer.step()` and explain why they must be cleared between updates.

Record your results and explanations in your personal notes. If a check fails, inspect shapes, data types, and the order of training operations. Ask for one hint if needed.
